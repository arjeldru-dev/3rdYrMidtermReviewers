Google AI Studio · Quick Guide

How to Get Google Gemini API Key

Google provides free access to Gemini API for developers, researchers, and students. You can generate a personal API key in about 60 seconds with no credit card required:

  1. 1

    Sign in to Google AI Studio

    Go to Google's official developer console at aistudio.google.com/app/apikey and sign in using your standard Google or university account.

    Open Google AI Studio Console
  2. 2

    Click "Create API Key"

    Once inside the dashboard, locate and click the "Create API key" button.

  3. 3

    Select Project & Create Key

    In the popup dialog, choose your project from the drop-down menu, then click the "Create key" button. The free tier is automatically enabled with zero payment info needed.

  4. 4

    Copy Your Key & Paste in Reviewer

    Click the copy icon to copy your generated key string (supports both AIza... and new AQ... formats). Return here and paste it into the Google Gemini API Key input box on the welcome screen.

Generous 1,500 RPD Quota

Gemini 2.0 Flash free tier grants 15 requests per minute and 1,500 requests per day (with automatic 1.5 Flash failover and persistent caching) — 75× more quota than preview tiers.

Client-Side Security

Your API key is saved exclusively in your device's local browser storage (localStorage) and communicates directly with Google's endpoint. No third-party server ever sees your key.
